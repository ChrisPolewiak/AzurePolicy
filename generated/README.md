# config/

Auto-generated JSON files consumed by Bicep at deployment time.
Generated by `scripts/generate_config_from_table.py` from the TSV exports in `configuration/`.

| File | Description |
| --- | --- |
| `initiatives.json` | Deduplicated list of initiatives to deploy |
| `assignments.json` | One entry per `Deploy=TRUE` row from `configuration/policy-assignments.tsv` |
| `parameters.json` | Parameter sets keyed by `Parameter Set` name |
| `assignment-identities.json` | UAMI and RBAC configuration for DINE/Modify assignments |

All files are excluded from git (`.gitignore`) and passed between pipelines as the `policy-generated` artifact.
Do not edit manually — regenerated on every Pipeline B run.
